## What just shipped (the 5-commit batch)

1. **Pre-resolved owner display.** `owner_display` is resolved canonically once
   in the marts (`fct_weekly_player_performance`, `mart_stat_leaderboard`,
   `mart_daily_roster_snapshot`) — nickname bridge, falling back to the raw
   box-score owner only for the defunct ownerless team. Every almanac consumer
   reads `owner_display` directly: **zero raw-owner-name holdouts**, so preferred
   names show everywhere (records, per-team tabs, optimal team, draft).
2. **Multi-team optimal-team attribution (the "Varland" fix).** Team / owner /
   team_id now come from a player's single most-recent stint (`MAX_BY` on one
   recency key), so a mid-season team change can't pair a team abbrev with a
   different stint's owner.
3. **Kiké's nickname.** `display_name` = "Kike 'Big Slur' Hernandez"; official
   `player_name` preserved. Design rule worth remembering: **`player_name` =
   official, `display_name` = nickname** — point any "official" surface at
   `player_name`. (Owners are simpler: always use the canonical `owner_display`.)
4. **Latest-week record highlight.** Burnt-orange/gold background on the Records
   tab for a genuine (small-tie or single-holder) all-time record whose latest
   instance is the current week. Formatting only → golden-neutral. Fires when a
   real record lands (MP11 had only saturated zero-ties, so none lit up).
5. **First-ever-shared-record framing.** A brand-new record set by N teams at
   once (no holder at the value predates this week) now renders as
   "**New Record … first in league history**" naming both setters, instead of
   "the Nth team to do so." Golden-neutral; activates on the next refresh — built
   specifically for the two-cycles-in-Week-12 case.
