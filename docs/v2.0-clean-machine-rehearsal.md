# v2.0 clean-machine rehearsal

This is the final local product gate before publishing the v2.0 GitHub release and asking Reddit for stranger feedback. Run it from the actual candidate ZIP on a Windows account or machine that has no Fantasy League Almanac checkout, `.env`, `.venv`, Google token, workbook ledger, Parquet data, or DuckDB data.

Do not substitute a clone, development worktree, or an archive assembled from uncommitted files. Record the candidate commit, ZIP SHA-256, Windows version, and pass/fail result. Never record the ESPN league ID, either ESPN cookie, a Google token, a workbook URL, a league-member name, or an unsanitized path.

## The supported v2.0 claim

The guided release journey is ESPN-first and Windows-first. A Windows user with an ESPN fantasy-baseball league can start from the release ZIP, provide the minimum local credentials and non-secret league facts, run the local Parquet/DuckDB/dbt pipeline, authorize the app-owned `drive.file` Google client, and receive a shareable workbook without manually editing `.env` or `config/leagues.yml`.

CBS guided onboarding is an urgent follow and is not included in this claim. Packaged sample mode is deferred and is not included in this claim. Automated browser-cookie acquisition is not included; the supported path is the bundled illustrated guide followed by hidden manual paste. These are explicit scope decisions that must appear in the release notes, Quickstart, Reddit post, and relevant Linear tickets rather than being implied or omitted.

A pending Google branding review does not by itself block the GitHub release or Reddit post. Wrong scopes, misleading permission language, missing or broken policy/support links, an unverified warning that is not clearly disclosed, unsafe credential handling, destructive behavior, a repeatable setup blocker, or materially misleading workbook output does block them.

## Run exactly this journey

1. Choose a supported ESPN league for the proof. A head-to-head league must
   have at least one completed matchup; a brand-new or late-start H2H league
   is useful refusal evidence but cannot prove the workbook journey. Put the
   unopened candidate ZIP in a normal Windows folder whose path contains
   spaces. A OneDrive-synced folder is preferred because this deliberately
   exercises both Windows argument quoting and the common synchronized-folder
   path shape.
2. Right-click the ZIP, choose **Extract All**, and open the extracted folder. Do not run anything from inside the compressed-folder view.
3. Confirm that `START_ALMANAC.cmd`, `ROTATE_ESPN_CREDENTIALS.cmd`, `QUICKSTART.md`, and the `docs` folder are visible.
4. Double-click `START_ALMANAC.cmd`. Do not open PowerShell, activate a virtual environment, install packages manually, or edit any configuration file.
5. If Python 3.13 is missing, follow only the launcher’s instruction, close its window, install 64-bit Python 3.13 with **Add python.exe to PATH** selected, and double-click `START_ALMANAC.cmd` again.
6. Let the launcher create `.venv` and install the pinned dependencies. If the internet fails, close the window only after reading its message, restore the connection, and double-click the launcher again. The rerun must finish without cleanup or manual repair.
7. At the setup prompt, press Enter to open the illustrated local ESPN guide. Inspect every illustration and sentence as a person who has never opened Developer Tools. Stop the release if a requested value is not explained at the moment it is needed.
8. Sign in to ESPN yourself in the normal browser. Copy the league ID, `espn_s2`, and `SWID` exactly as the guide explains. Paste cookies only into the hidden terminal prompts. Confirm that neither value appears on screen.
9. Enter the first season. Leave final season blank for an ongoing league. Confirm that the validation summary shows the intended league name, team count, format, and complete requested season range before allowing the long run.
10. At `Create the almanac now? [Y/n]`, press Enter. Enter must mean Yes.
11. Complete Google authorization. Confirm the application name and support/policy links are honest, the requested access has not expanded beyond the app-created-file `drive.file` contract, and any still-pending branding warning matches the release disclosure.
12. Approve link sharing only when the application explicitly asks. When the run finishes, open the workbook link in a signed-out/private browser window and confirm that a league member with the link can view it.
13. Check Home, Records, Advanced Standings, Draft Recap, and at least one team page. Stop if the league format is wrong, season coverage is unexpectedly short, a team is attributed to the wrong franchise, auction prices are missing or snake concepts were invented, provisional results look final, or any material number is misleading.
14. Close the workbook and double-click `START_ALMANAC.cmd` once more. The dependency phase must report that packages are already ready. Exit before starting another long run if the validated setup and existing output are already sufficient for the gate.

## Pass/fail sentence

Pass only if this sentence is true:

> Starting only from the actual candidate ZIP, Kyle used the visible double-click journey and bundled instructions, made no manual configuration edits, received a materially correct shareable workbook, and encountered no unresolved credential, destructive-data, permission, or setup risk.

If any part is false, do not tag, release, or post. Record only sanitized symptoms, fix the candidate, and repeat from a new extraction.

## After a pass

Publish through the maintainer's local release checklist, including the private PII inventory, tag-built OAuth bundle, ZIP census, SHA-256, public GitHub Release, and live policy/support-link checks. A non-Kyle completion is not required before Reddit: Reddit is the first broad stranger-validation event.

Observe Reddit and GitHub feedback for 48–72 hours. At least one credible non-Kyle completion plus no unresolved safety or material-correctness blocker gates the later LinkedIn post.
